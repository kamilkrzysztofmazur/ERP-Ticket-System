# ERP Ticket System

Prosta aplikacja konsolowa do zarządzania zgłoszeniami (ticketami) w systemie ERP.
Pozwala na dodawanie, przeglądanie i zarządzanie zgłoszeniami z wykorzystaniem bazy SQL Server.

## Technologies
- C#
- .NET
- SQL Server
- ADO.NET
- Git

## Features
- Tworzenie zgłoszeń
- Wyświetlanie listy zgłoszeń
- Połączenie z bazą danych SQL Server

## Project Structure
- Models – modele danych (Ticket)
- Services – logika biznesowa
- Database – połączenie z bazą danych
